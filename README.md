# ระบบจองคิวแจ้งปัญหาแอป

🌐 **เว็บจริง:** https://appdpremium.onrender.com
🔐 **หน้าแอดมิน:** https://appdpremium.onrender.com/admin (ไม่มีลิงก์จากหน้าลูกค้า)

React + Vite (หน้าบ้าน) · Node.js + Express (หลังบ้าน) · Google Sheet ผ่าน Apps Script (ฐานข้อมูล) · Render ฟรี (Singapore)

## ความสามารถ

**ลูกค้า**
- `/` หน้าหลัก มีปุ่ม ลงคิว / เช็คคิว / ติดต่อแอดมิน / คิววันนี้ และมีปฏิทินคิวว่าง
  - วันนี้แสดง ว่าง / กำลังแก้ไข / เสร็จแล้ว
  - วันในอนาคตแสดงเฉพาะจำนวนคิวว่าง
- `/book` ลงคิว ช่องที่ต้องกรอก
  - แอป, ปัญหา (มี "อื่นๆ" ให้พิมพ์เอง), รายละเอียด
  - วันที่ต้องการ
  - ชื่อ LINE, อีเมลที่มีปัญหา, ชื่อ family, อีเมลลูกค้า (ใช้แจ้งผล)
  - วันหมดรอบบิล, รอบเดือน (1/3/6/12 เดือน หรืออื่นๆ)
- `/check` เช็คสถานะด้วยเลข PIN 4 หลัก
- `/contact` ปุ่มไป LINE ร้าน
- ประกาศสีแดงจากแอดมินแสดงด้านบนทุกหน้า (สูงสุด 3 ประกาศ)
- ถ้าระบบขัดข้อง จะแสดงข้อความภาษาไทยพร้อมปุ่มติดต่อแอดมินทาง LINE

**แอดมิน**
- ดูคิวรายวัน แบ่ง 3 สถานะ: รอแก้ไข / กำลังแก้ไข / แก้ไขเสร็จแล้ว
- ปุ่มบนการ์ดคิว: คัดลอกเมลที่มีปัญหา, คัดลอกชื่อ family, เริ่มแก้ไข, ย้อนสถานะ
- ปุ่ม **แก้ไขเสร็จแล้ว+แจ้งลูกค้า** เปิดป๊อปอัปอีเมลที่เขียนไว้ให้แล้ว กดส่งแล้วจะเปิด Gmail
- ปุ่ม **ตั้งค่า**: ประกาศ, จำนวนคิวต่อวัน, วันปิดรับคิว, จำนวนคิวเฉพาะวัน, ลิงก์ LINE (แก้แล้วต้องกด **บันทึกการตั้งค่า**)

## รูปแบบรหัสคิว

`A01-231069-1111` = คิวที่ **01** ของวันที่ **23/10/(25)69** และ PIN **1111**

- เลขลำดับเริ่มนับใหม่ทุกวัน
- PIN สุ่มไม่ซ้ำกับคิวในเดือนนี้และคิวที่ยังไม่เสร็จ จึงวนใช้ใหม่ได้ทุกเดือน
- การเช็คคิวจำกัดไว้ 10 ครั้งต่อ 5 นาทีต่อ IP (กันการสุ่มเดา PIN) และการลงคิวจำกัดไว้ 10 ครั้งต่อ 10 นาทีต่อ IP

## Google Sheet

ข้อมูลทั้งหมดอยู่ใน Google Sheet ของร้าน แบ่งเป็น 4 ชีต

| ชีต | ใช้ทำอะไร |
|---|---|
| `Queues` | คิวทั้งหมด (สลับลำดับคอลัมน์ได้ ระบบอ่านตามชื่อหัวตาราง) |
| `Archive` | คิวที่เสร็จแล้วและเก่ากว่า 90 วัน ระบบย้ายมาให้อัตโนมัติวันละครั้ง |
| `Options` | รายการแอปและปัญหาใน dropdown (1 แถว = 1 ปัญหา) **แก้ใน Sheet ได้เลย** |
| `Settings` | ค่าที่ตั้งจากหน้าแอดมิน (ไม่ควรแก้ตรงนี้) |

> หลังแก้ใน Sheet เว็บจะอัปเดตภายใน ~15 วินาที (เซิร์ฟเวอร์พักข้อมูลไว้)
> ถ้าเผลอลบข้อมูล: Google Sheet → **ไฟล์ → ประวัติเวอร์ชัน**

### ตั้งค่า Apps Script (ทำครั้งเดียว)

1. ใน Google Sheet ไปที่ **ส่วนขยาย → Apps Script**
2. วางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs) ทับโค้ดเดิม แล้วแก้ `const SECRET = '...'` เป็นข้อความสุ่มยาวๆ จากนั้นกดบันทึก
3. ตั้งค่า **Deploy → New deployment**
   - ⚙️ เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy
4. กดอนุญาตสิทธิ์ ถ้าขึ้น "Google hasn't verified this app" ให้กด **Advanced → Go to … (unsafe)** แล้วกด Allow
5. คัดลอก **Web app URL** (ลงท้าย `/exec`) ไปใส่ใน `APPS_SCRIPT_URL` และใส่ SECRET ใน `APPS_SCRIPT_SECRET`

> **ถ้าแก้ Code.gs ภายหลัง** ให้กด **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy**
> อย่ากด New deployment เพราะ URL จะเปลี่ยน
> ถ้าเพิ่มหรือแก้ช่องในฟอร์ม ไม่ต้องแก้ Code.gs

## Render (โฮสต์เว็บ)

ตั้งค่าไว้แล้วใน [`render.yaml`](render.yaml): แพ็ก Free, region Singapore, health check ที่ `/api/health`

**Environment Variables** (Render → บริการ → Environment)

| ตัวแปร | ค่า |
|---|---|
| `ADMIN_PASSWORD` | รหัสเข้าหน้าแอดมิน |
| `APPS_SCRIPT_URL` | URL Web app ของ Apps Script |
| `APPS_SCRIPT_SECRET` | ต้องตรงกับ `SECRET` ใน Code.gs |
| `VITE_LINE_URL` | ลิงก์ LINE ร้าน (สำรองไว้ให้ปุ่ม LINE ใช้ได้แม้เซิร์ฟเวอร์ล่ม) |
| `JWT_SECRET` | Render สุ่มให้เอง |
| `NODE_ENV`, `TZ` | `production`, `Asia/Bangkok` (ตั้งไว้แล้ว) |

> **ลืมรหัสแอดมิน:** แก้ `ADMIN_PASSWORD` ใน Render → Environment แล้วกด Save ระบบจะรีสตาร์ทเอง

### กันเว็บหลับด้วย UptimeRobot

Render ฟรีจะหลับเมื่อไม่มีคนเข้า 15 นาที คนแรกที่เข้าหลังจากนั้นต้องรอสูงสุด ~1 นาที แก้ได้ด้วยการให้ UptimeRobot เรียกเว็บเป็นระยะ

1. สมัครฟรีที่ [uptimerobot.com](https://uptimerobot.com)
2. กด **+ New monitor** แล้วกรอก
   - Monitor type: **HTTP(s)**
   - Friendly name: `appdpremium`
   - URL: `https://appdpremium.onrender.com/api/health`
   - Monitoring interval: **5 minutes**
3. (แนะนำ) ติ๊กอีเมลใน **Alert contacts** ถ้าเว็บล่ม จะได้อีเมลแจ้งเตือน
4. กด **Create monitor**

`/api/health` ไม่ได้อ่าน Google Sheet จึงไม่เปลืองโควตา Apps Script

> ⚠️ **ข้อควรรู้**
> - เปิดตลอด 24 ชั่วโมงจะใช้ชั่วโมงฟรี ~744 จาก 750 ชั่วโมง/เดือน **ห้ามสร้างบริการฟรีตัวอื่นในบัญชี Render เดียวกัน** ไม่งั้นชั่วโมงหมดก่อนสิ้นเดือน แล้วเว็บจะหยุดจนถึงเดือนถัดไป
> - Render ไม่สนับสนุนการปลุกเว็บแบบนี้ และอาจเปลี่ยนเงื่อนไขในอนาคต ถ้าต้องการให้เร็วตลอดแบบไม่มีความเสี่ยง ให้อัปเกรดเป็นแพ็ก **Starter**

## รันในเครื่อง (สำหรับแก้โค้ด)

```bash
npm install
cp .env.example .env     # กรอกค่าตามตาราง Environment Variables
npm run dev              # เปิด http://localhost:5173 (แก้โค้ดแล้วหน้าเว็บอัปเดตเอง)
```

> ⚠️ ถ้า `.env` มี `APPS_SCRIPT_URL` อยู่ การทดสอบในเครื่องจะ**เขียนลง Google Sheet จริง**ที่ลูกค้าใช้
> ถ้าจะทดสอบโดยไม่กระทบของจริง ให้ลบ `APPS_SCRIPT_URL` ออกชั่วคราว ระบบจะใช้ข้อมูลจำลองในหน่วยความจำแทน

**ไอคอน:** วางไฟล์ `.png` พื้นโปร่งใสไว้ใน `client/public` แล้วเรียกด้วย `<Icon name="ชื่อไฟล์" />` สีของไอคอนจะเปลี่ยนตามปุ่มเอง
